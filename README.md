# C++ Practice - Loop Lab

C++ loop practice programs divided into three levels: Beginner, Intermediate, and Challenge.

### Beginner
- Print 1 to 10 (`Beginners/print1-10.cpp`)
- Print 10 down to 1 (`Beginners/print10-1.cpp`)
- Print even numbers up to 20 (`Beginners/printeven-20.cpp`)
- Print odd numbers up to 20 (`Beginners/printodd-20.cpp`)
- Print multiplication table of a number (`Beginners/printmultinum.cpp`)

### Intermediate
- Sum of 1 to N (`Intermediate/sum1ton.cpp`)
- Count the digits in a number (`Intermediate/digtCount.cpp`)
- Reverse a number (`Intermediate/revNum.cpp`)
- Sum of the digits of a number (`Intermediate/sumNum.cpp`)
- Check whether a number is a palindrome (`Intermediate/palindrome.cpp`)

### Challenge
- Check whether a number is prime (`Challenge/prime.cpp`)
- Print all primes in a range (`Challenge/primeRange.cpp`)
- Print the Fibonacci series (`Challenge/fibonacci.cpp`)
- Check for an Armstrong number (`Challenge/armstrong.cpp`)
